# TalentHub AI Roadmap

This document outlines the planned features, enhancements, and architectural upgrades for TalentHub AI. 

## Phase 1: Core Foundation (Current)
- [x] Next.js App Router Setup
- [x] Supabase Authentication (Candidate vs Recruiter roles)
- [x] UI System Implementation (shadcn/ui, Tailwind CSS)
- [x] Core Job Board (Listing, Filtering, Details)
- [x] Application Tracking System (ATS) basics
- [x] Dynamic Analytics Dashboard

## Phase 2: AI Integration & Matching
- [ ] **Resume Parsing:** Implement PDF parsing to automatically extract skills, work history, and education to build user profiles.
- [ ] **AI Job Matching Engine:** Utilize OpenAI or similar LLMs to calculate a "Fit Score" for candidates applying to specific jobs.
- [ ] **Automated Cover Letter Generation:** Allow candidates to generate tailored cover letters based on their profile and the specific job posting.

## Phase 3: Communication & Collaboration
- [ ] **In-App Messaging:** Real-time chat between recruiters and candidates.
- [ ] **Interview Scheduling:** Integration with Google Calendar/Outlook to schedule interviews directly within the platform.
- [ ] **Video Conferencing:** Embedded WebRTC video calls for initial screening rounds.
- [ ] **Team Collaboration:** Allow multiple recruiters from the same company to collaborate on a hiring pipeline, leave notes, and vote on candidates.

## Phase 4: Enterprise & Scale
- [ ] **Advanced Reporting:** Exportable PDF/CSV reports for hiring velocity, diversity metrics, and time-to-fill.
- [ ] **Custom Assessment Tests:** Employers can build custom multiple-choice or coding assessments for candidates to take before applying.
- [ ] **Mobile Application:** Develop a React Native companion app for candidates to swipe through jobs and track applications on the go.
- [ ] **Public API:** Allow enterprises to integrate their internal HR software with TalentHub AI.

---

*Note: This roadmap is a living document and is subject to change based on user feedback and project priorities.*
